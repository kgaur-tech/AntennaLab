# AntennaLab Development Phase Plan

## Phase 0: Scope Freeze
- Confirm requirement schema and domain vocabulary
- Freeze engineering model interfaces
- Define deterministic output terminology
- Establish MVP and engineering constraints

## Phase 1: Engineering Core
- Unit conversion layer
- RF constants and validators
- Geometry primitives
- Initial model families: dipole, monopole, Yagi-Uda
- Analytical checks and deterministic tests

## Phase 2: Backend
- FastAPI setup
- Pydantic models and validation
- Recommendation service
- Database and worker integration points

## Phase 3: UI
- Requirement wizard
- Recommendation results screen
- Parameter editing and design workspace

## Phase 4: Simulation and Visualization
- 3D geometry preview
- Pattern preview
- Plotting and update debouncing

## Phase 5: Optimization and Revisions
- Sweeps and comparison metrics
- Design revision history
- Candidate generation and scoring

## Phase 6: Datasheets and Learning
- Export-ready documentation
- Educational content and build guidance

## Phase 7: Manufacturing and Hardening
- Quote workflow
- Reliability, security, and production readiness
